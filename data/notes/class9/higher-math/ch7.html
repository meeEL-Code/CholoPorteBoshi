৭. অসীম ধারা

গুরুত্বপূর্ণ শর্ত

অসীম গুণোত্তর ধারার সমষ্টি থাকার শর্ত: |r| < 1

r ≥ ১ বা r ≤ −১ হলে সমষ্টি থাকবে না (অসীমে চলে যাবে)।

সূত্রাবলি

  • সমান্তর ধারা: aₙ = a + (n−1)d, Sₙ = n/2[2a + (n−1)d]
  • গুণোত্তর ধারা: aₙ = arⁿ⁻¹, Sₙ = a(rⁿ−1)/(r−1) [r>1], Sₙ = a(1−rⁿ)/(1−r) [r<1]
  • অসীম সমষ্টি: S∞ = a/(1−r)

আবৃত দশমিককে ভগ্নাংশে রূপান্তর

অসীম G.P. সূত্র ব্যবহার করা।
যেমন: 0.3̄ = 0.3 + 0.03 + 0.003 + ... = 0.3/(1−0.1) = 1/3
