১০. স্থির তড়িৎ

তড়িৎ আধান

দুই প্রকার — ধনাত্মক ও ঋণাত্মক।

  • সমান আধান → বিকর্ষণ
  • অসমান আধান → আকর্ষণ

কুলম্বের সূত্র

F = kq₁q₂/r²

  • k = 9×10⁹ N·m²/C²

তড়িৎ ক্ষেত্র ও বিভব

  • E = F/q = kQ/r²
  • V = W/q = kQ/r

ধারকত্ব (C)

  • C = Q/V
  • একক: ফ্যারাড (F)
  • সমান্তরাল: C = C₁ + C₂
  • শ্রেণিতে: 1/C = 1/C₁ + 1/C₂

গুরুত্বপূর্ণ সূত্র

  • F = kq₁q₂/r²
  • E = kQ/r²
  • V = kQ/r
  • C = Q/V
