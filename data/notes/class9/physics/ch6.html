৬. বস্তুর উপর তাপের প্রভাব

তাপ ও তাপমাত্রা

  • তাপ: এক বস্তু থেকে অন্য বস্তুতে শক্তির স্থানান্তর
  • তাপমাত্রা: বস্তুর তাপীয় অবস্থার পরিমাপ

তাপমাত্রা রূপান্তর

  • সেলসিয়াস → ফারেনহাইট: F = (9C/5) + 32
  • সেলসিয়াস → কেলভিন: K = C + 273

তাপের প্রভাব

প্রসারণ: কঠিন < তরল < বায়বীয় (গ্যাসে সবচেয়ে বেশি)

  • দৈর্ঘ্য প্রসারণ: L = L₀(1 + αΔT)
  • ক্ষেত্রফল প্রসারণ: A = A₀(1 + βΔT)
  • আয়তন প্রসারণ: V = V₀(1 + γΔT)
  • α : β : γ = 1 : 2 : 3

আপেক্ষিক তাপ (s)

1 kg পদার্থের তাপমাত্রা 1K বাড়াতে প্রয়োজনীয় তাপ।

  • Q = msΔT
  • পানির আপেক্ষিক তাপ = 4200 J/kg·K

সুপ্ততাপ

অবস্থা পরিবর্তনের সময় গৃহীত/বর্জিত তাপ।

  • Q = mL
  • বরফের গলন সুপ্ততাপ = 336,000 J/kg
  • পানির বাষ্পীভবন সুপ্ততাপ = 2,260,000 J/kg

মনে রাখার টিপস

  • বরফ গলে না — কেবল অবস্থা পরিবর্তন
  • α : β : γ = 1 : 2 : 3 — এটা পড়ার প্রশ্নে আসে
