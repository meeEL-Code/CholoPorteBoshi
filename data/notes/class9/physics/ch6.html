৬. বস্তুর উপর তাপের প্রভাব

মূল বিষয়

দৈর্ঘ্য/ক্ষেত্রফল/আয়তন প্রসারণ সহগ, আপেক্ষিক তাপ, ক্যালরিমিতির মূলনীতি।

গুরুত্বপূর্ণ সূত্র

  • দৈর্ঘ্য প্রসারণ সহগ α = ΔL / (L₁·ΔT)
  • ক্ষেত্রফল প্রসারণ সহগ β = ২α
  • আয়তন প্রসারণ সহগ γ = ৩α
  • α : β : γ = ১ : ২ : ৩
  • তাপ Q = msΔT (s = আপেক্ষিক তাপ)
  • সুপ্ততাপ Q = mL
  • সেলসিয়াস → ফারেনহাইট: F = (৯C/৫) + ৩২
  • সেলসিয়াস → কেলভিন: K = C + ২৭৩

গুরুত্বপূর্ণ তথ্য

  • পানির আপেক্ষিক তাপ = ৪২০০ J/kg·K
  • বরফের গলন সুপ্ততাপ = ৩৩৬,০০০ J/kg
  • পানির বাষ্পীভবন সুপ্ততাপ = ২,২৬০,০০০ J/kg

ক্যালরিমিতির মূলনীতি

গৃহীত তাপ = বর্জিত তাপ

পরীক্ষার জন্য গুরুত্বপূর্ণ

  • ক্যালরিমিতি নীতি প্রয়োগ করে মিশ্রণের চূড়ান্ত তাপমাত্রা নির্ণয়
  • রেললাইনের পাতের মাঝে ফাঁকা রাখার গাণিতিক কারণ
  • প্রসারণ সহগ থেকে পরিবর্তিত দৈর্ঘ্য/ক্ষেত্রফল/আয়তন নির্ণয়
